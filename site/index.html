Vì sao chọn Chạy Runtime

Contract nhỏ cho IDE AI, verify mạnh cho repo thật

Người dùng không cần nhớ nhiều lệnh. cr go tạo graph + sequence + handoff; IDE AI đọc một file nhỏ rồi code đúng phạm vi.

Feature graph là source of truth

memory/feature_graph.json chứa user flow, sequence diagram, nhánh lỗi, code targets và acceptance checks.

Patch guardrail

Reject sửa ngoài scope, sửa docs human-owned khi chưa approve, đụng secrets, xóa validation hoặc thêm anti-pattern.

Handoff giảm token

IDE session mới đọc memory/ai_handoff.json trước, thay vì đọc lại cả repo và đoán việc đang làm.

Design pattern rules

AI phải giữ local pattern, SOLID, validation, error handling, security checks, accessibility và tests.

IDE config

cr config tạo instruction chung cho Codex, Claude, Antigravity, GitHub Copilot, Cursor, Kiro hoặc manual mode.

Verify sau khi AI code

cr verify, patch check và token report cho người dùng biết patch còn hỏng gì và tiết kiệm token bao nhiêu.

IDE AI external mode

Không điều phối subagent, chỉ cấu hình IDE và verify patch

Codex, Claude, Antigravity, GitHub Copilot, Cursor hoặc Kiro code ở ngoài. Chạy Runtime chỉ tạo contract, handoff và guardrail local để IDE AI biết phải đọc gì và không được sửa gì.

// config

cr config

Tạo .chay/ide/CHAY_IDE_INSTRUCTIONS.md và memory/ide_config.json cho IDE AI đang dùng.

// one command

cr go

Không cần biết file từ đầu. Runtime scan repo, chọn context, tạo graph, sequence diagram, work note và handoff.

// verify

cr verify

Sau khi IDE AI code xong, runtime check result note, patch scope, human-owned docs, secrets, token budget và OWASP prompts.

Workflow chính

Graph → sequence → handoff → IDE AI → verify

Local UI vẫn dùng được để inspect state, nhưng workflow chính là IDE-first. File quan trọng nhất cho session mới là memory/ai_handoff.json.

Bắt đầu nhanh

Cấu hình IDE AI, rồi để runtime tạo contract

Một lần config cho IDE đang dùng, sau đó mỗi tính năng chỉ cần cr go. Nếu mở session mới, chạy cr go không tham số để refresh handoff.

terminal 
# 1 · cài bộ công cụ
npm install -g chay-runtime@latest

# 2 · thiết lập ngay trong dự án của bạn
cd du-an-cua-ban
cr start

# 3 · cấu hình IDE AI bên ngoài
cr config codex,claude,anti,github-copilot,cursor,kiro

# 4 · tạo user flow, sequence diagram, work note và handoff
cr go "User applies to job"

# 5 · mở IDE AI và bảo nó đọc handoff
# Read memory/ai_handoff.json and continue the task.

# 6 · sau khi IDE AI sửa code
cr verify
cr handoff
Tài liệu lệnh

Lệnh chính cho workflow hiện tại

Các lệnh cũ như cr run, dispatch, workpack vẫn còn cho legacy/internal scripting. UX chính là config IDE, tạo handoff và verify patch.

Khởi tạo & thiết lập cr start cr check

Tạo thư mục runtime local và kiểm tra CLI/login khi cần. Không bắt buộc chia main/worker trong workflow mới.

Cấu hình IDE AI cr config codex,claude,anti,github-copilot,cursor,kiro cr config check

Tạo .chay/ide/CHAY_IDE_INSTRUCTIONS.md và memory/ide_config.json. IDE AI code ở ngoài; Chạy Runtime giữ contract và verify.

Tạo / resume task cr go "User applies to job" cr go cr go "User applies to job" --files src/applyService.js

cr go scan repo, chọn context, tạo feature graph, user flow, sequence diagram, PlantUML, work note và handoff. Không tham số thì refresh handoff cho session mới.

Handoff cho session mới cr handoff

Ghi memory/ai_handoff.json để IDE AI đọc nhanh trạng thái, files liên quan, graph, sequence, PlantUML, guardrails và OWASP API review prompts.

Verify sau khi IDE AI code cr verify cr patch check --diff .chay/tmp/current.diff --work memory/<agent>_work_note.json

Kiểm result note, patch scope, docs human-owned, secrets, token budget và các violation hiện tại.

Token saving cr token report

So sánh token của Chạy context với ước lượng toàn repo để chứng minh session mới đọc ít hơn.

Local inspector cr ui serve --port 7770

UI local vẫn dùng để inspect graph, selected files, handoff, runtime status, token/eval report và patch checks. Worker runner trong UI là legacy/advanced.

Advanced / legacy cr task "..." cr pack "..." cr run cr dispatch codex --agent=codex

Còn giữ cho automation cũ và scripting, nhưng không phải workflow chính cho IDE AI external mode.

Mô hình an toàn

Mặc định là từ chối

Chạy Runtime "fail closed". Nếu tác tử bước ra ngoài hợp đồng, runtime sẽ chặn lại.

  • Ghi chú quá dài
  • Ghi chú kết quả không khớp schema
  • Bản vá đổi quá nhiều file
  • Bản vá thêm quá nhiều dòng
  • Sửa file ngoài danh sách cho phép
  • Tác tử đọc Markdown kiểm toán
  • Ghi chú thiếu quy tắc kiến trúc / SOLID
  • Log kết quả tự do quá lớn
